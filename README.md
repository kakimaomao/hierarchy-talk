# 階層は、デザイナーの理解そのもの

デザインチーム定例（2026.09.18）での5分発表のスライドです。

**わかりやすさは、どこから来るのか** — UIで一番大事なのは「この画面が何なのか、自然にわかること」で、
それをつくる方法が階層。そして階層は、デザイナー自身の理解がそのまま画面に出たもの、という話。

## 見かた

`index.html` をブラウザで開いてください。

| キー | |
|---|---|
| `←` `→` / `Space` | ページ送り |
| `N` | スピーカーノート（各ページの尺と話し方）|
| `F` | 全画面 |

## 構成

1. つかみ — 使えないユーザーなんて、いない
2. 主張 — UIで一番大事なのは「わかる」こと
3. 核心 — 階層は、デザイナー自身の理解がそのまま画面に出たもの
4. 階層をつくる4つの手段
   1. すべてを同じ強さにしない
   2. 脇役を弱める
   3. ラベルを見直す（ただし、ラベルが主役になる場面もある）
   4. 意味と見た目を分ける
5. 締め — 動く前に、まず「伝わる」こと
